# Sistem Profiling Data Anak Asuh - UPT RPA Wiloso Projo
Aplikasi web pengelolaan data anak asuh berbasis Streamlit dan SQLite.

## Fitur Utama
1. Keamanan Login & Hak Akses (Admin, Pengasuh, Viewer)
2. Database Master Anak & Repositori Scan Dokumen Legalitas
3. Profil Bio-Psiko-Sosial, Kesehatan & Log Harian Pengasuh
4. Pemantauan Akademik, Minat & Bakat Prestasi
5. Aging-Out Plan (15+ Tahun) & Tracing Alumni
6. Quick-Print Portofolio Individual & Ekspor Excel
7. Log Audit Keamanan System

## Cara Penggunaan
1. Install library: pip install -r requirements.txt
2. Jalankan aplikasi: streamlit run app_profiling_wiloso_projo-v3.py
